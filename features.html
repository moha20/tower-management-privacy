تطبيق برج الماسة السكني الفاخر

الحل التقني الشامل لقاطني وإدارة وحراسة برج الماسة. يجمع بين أحدث تقنيات السحابة الذكية، إدارة الصيانة، حجز المرافق، تصاريح الجراج والزوار عبر الـ QR، وغرف المحادثات الفورية المتعددة الوسائط.

🔑 تسجيل الدخول والمصادقة المعتمدة

بوابة تسجيل دخول آمنة تدعم كافة أدوار البرج مع فحص دقيق للبيانات واعتماد إداري رسمي قبل التفعيل لضمان أعلى درجات الخصوصية والأمان لقاطني البرج.

  • ✓ دعم تسجيل السكان والملاك، أفراد الأمن، وفريق الإدارة والتشغيل.
  • ✓ ربط الحساب برقم الشقة (الوحدة) ورقم الدور ونوع الإقامة (مالك / مستأجر).
  • ✓ شاشة مراجعة فورية لحالة الطلب مع إمكانية إلغاء وحذف الحساب في أي وقت.

🏠 لوحة تحكم الساكن والخدمات الفاخرة

واجهة رئيسية أنيقة تم تصميمها بعناية لتمنح الساكن وصولاً فورياً لكافة خدمات البرج الفندقية بنقرة واحدة، مع متابعة حية لجميع الإعلانات والتعميمات الرسمية.

  • 🚨 زر استغاثة فوري (SOS): إرسال تنبيه طوارئ عاجل مع تحديد الشقة لمكتب الأمن والإدارة خلال ثوانٍ.
  • ✓ تقديم ومتابعة بلاغات الصيانة الدورية مع إرفاق الصور ومتابعة وصول الفني.
  • ✓ حجز مرافق البرج الفاخرة: النادي الصحي، الجيم، المسبح، وقاعات المناسبات.
  • ✓ استعراض سجل السكان وخطة الإخلاء في حالات الطوارئ.

💬 محادثات البرج الفورية المتعددة الوسائط

غرف محادثات حيّة متكاملة تربط السكان بفريق الصيانة والأمن والإدارة، تدعم المراسلة النصية، إرسال الصور، والرسائل الصوتية المباشرة مع مزامنة سحابية فورية.

  • 🎙️ تسجيل وإرسال الملاحظات الصوتية المباشرة مع مشغل صوتي مدمج.
  • 📷 إرفاق صور المشكلات الفنية وإيصالات السداد بدقة عالية.
  • ⚡ مزامنة حية وفورية عبر خوادم Google Cloud Firestore.

🚗 إدارة الجراج ومسح تصاريح الدخول الذكية (QR)

منظومة دخول متطورة لبوابات البرج والجراج الذكي تعتمد على مسح رمز الاستجابة السريع (QR Code) لتنظيم دخول سيارات السكان واستقبال الزوار بسلاسة وأمان.

  • ✓ إصدار تصاريح دخول رقمية لزوار الشقق مع رمز QR فريد وتاريخ انتهاء محدد.
  • 🔍 كاميرا ماسح ضوئي ذكية مخصصة لأفراد الأمن للتحقق الفوري من صلاحية التصريح.
  • ✓ عرض بيانات الزائر، رقم الشقة المضيفة، ونوع التصريح بلحظات معدودة.

📊 لوحة تحكم الإدارة الشاملة واعتماد الحسابات

مركز قيادة وتحكم متكامل لإدارة برج الماسة، يتيح المتابعة الدقيقة لكافة مؤشرات الأداء، طلبات اعتماد الحسابات، وصلاحيات تنشيط وتعطيل المستخدمين.

  • ✓ اعتماد ورفض الحسابات: مراجعة بيانات عقود السكان وتفعيل الحسابات بضغطة زر.
  • 🔒 صلاحيات الإدارة: إمكانية تعطيل الحساب (Un-active) أو إعادة تنشيطه (Active) أو حذفه نهائياً.
  • 🛡️ تبويب الحسابات المحذوفة ذاتياً: عند قيام أي ساكن بحذف حسابه، يتم تمييزه في تبويب خاص مع حفظ كامل سجلات المحادثات والشكاوى للإدارة.

👮 بوابة وأجهزة أمن وحراسة البرج

واجهة مخصصة لمكاتب الأمن والبوابات تتيح حصر حركة الدخول والخروج، مراقبة أجهزة الإنذار، وتلقي استغاثات الطوارئ للتحرك الفوري ومساندة السكان.

  • ✓ شاشة خاصة بأفراد الحراسة تدعم العمل على أجهزة الآيباد والأجهزة اللوحية.
  • ✓ سجل إلكتروني مباشر لكافة المركبات المتواجدة داخل الجراج.
  • ✓ زر اتصال سريع بأرقام الطوارئ الرسمية (الشرطة، الإسعاف، الدفاع المدني).

  • ✓ ماسح QR ضوئي فوري للتحقق من تصاريح دخول الزوار والشاحنات.
  • ✓ سجل رقمي لمراقبة تدفق دخول وخروج السيارات ومواقف السكان.
  • ✓ شاشة استلام فورية لبلاغات الطوارئ والاستغاثات (SOS Monitor).
  • ✓ قناة تواصل وإنتركم داخلي للتنسيق مع إدارة البرج والوحدات.

  • ✓ لوحة تحكم تفاعلية لإحصائيات الإشغال ونسب الإنجاز والمصروفات.
  • ✓ مراجعة طلبات التسجيل واعتماد حسابات السكان الجدد وتجميدها.
  • ✓ إسناد بلاغات الصيانة للفرق الفنية والشركات مع التكلفة.
  • ✓ تنظيم جداول حجوزات المرافق وأوقات الصيانة الدورية.
  • ✓ نشر التعميمات والإشعارات الجماعية لجميع سكان البرج.
  • ✓ سجل التعداد والإحصاء السكاني لخطط الإخلاء والسلامة.

🔄 دورة حياة وحالات الحسابات (Account Statuses)

يخضع كل مستخدم لنموذج تدقيق أمني يضمن سلامة وهويات قاطني البرج:

معتمد ونشط (approved)
الحساب موثق ومفعل بالكامل، يتمتع بكافة صلاحيات دوره في التطبيق.
قيد المراجعة (pending)
تم التسجيل وينتظر مراجعة وتأكيد إدارة البرج للتأكد من هوية ورقم شقة الساكن.
مرفوض (rejected)
تم رفض الطلب لعدم مطابقة بيانات الوحدة أو وجود خطأ في التسجيل.
معطل مؤقتاً (inactive)
تجميد إداري مؤقت للحساب لحين مراجعة إدارة البرج (متأخرات أو انتهاء عقد).
محذوف ذاتياً (deletedBySelf)
قام المستخدم بطلب حذف حسابه عبر التطبيق؛ تُعطل إمكانية دخوله مع حماية السجلات المالية السابقة.

🔄 Account Lifecycle & Verification Statuses

Every account is governed by a rigorous security verification workflow:

Approved & Active (`approved`)
Fully verified user with unrestricted access to authorized features based on their role.
Pending Review (`pending`)
Registration submitted, awaiting management verification of apartment ownership or tenancy.
Rejected (`rejected`)
Application denied due to mismatched apartment records or unauthorized access attempt.
Temporarily Inactive (`inactive`)
Temporarily suspended by property management pending renewal or payment settlement.
Deleted by User (`deletedBySelf`)
User exercised in-app account deletion. Login disabled while audit logs remain secure.
